# Personal Portfolio Website

A modern and responsive personal portfolio website created using HTML, CSS, JavaScript, and Bootstrap.

## Features

* Responsive Design
* Modern User Interface
* About Me Section
* Skills Section
* Projects Showcase
* Contact Form Validation
* Bootstrap Components
* Mobile Friendly Layout

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5

## Project Objective

This project was developed as part of a Full Stack Development Internship Program to demonstrate front-end development skills and responsive web design concepts.
