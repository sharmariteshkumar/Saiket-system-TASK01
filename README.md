# Personal Portfolio Website

A modern and responsive Personal Portfolio Website developed using HTML, CSS, JavaScript, and Bootstrap 5.

This project was created as part of the **Full Stack Development Internship Program at Saiket Systems**. The website showcases personal information, skills, projects, and a contact form with client-side validation.

---

## 📌 Internship Information

**Organization:** Saiket Systems

**Internship Domain:** Full Stack Development

**Task:** Task 1 – Create a Static Portfolio Website

### Task Requirements

* Create a responsive portfolio website
* Add a Homepage section
* Add a Projects section with placeholders
* Add a Contact Form
* Implement JavaScript Form Validation
* Use Bootstrap/Tailwind for styling
* Ensure responsive design across devices
